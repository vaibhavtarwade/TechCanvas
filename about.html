About TechCanvas

The story behind this student blog, what I'm learning, and why documenting the process matters.

The Mission

About the Blog

TechCanvas is a student-created blog built as part of a college class activity. It is a place to document what I’m learning, explore technology topics, and share ideas that I find interesting throughout my engineering studies.

In computer science and engineering coursework, we frequently learn complex theoretical models, write code for lab assignments, and tackle semester projects. However, having a dedicated space to synthesize those concepts into clear, written reflections deepens understanding far more than just passing an exam.

Why "TechCanvas"?

The name TechCanvas reflects the philosophy that technology is an expansive canvas for creative problem-solving. Whether it's writing clean JavaScript, configuring distributed cloud tools, or understanding how machine learning algorithms work under the hood, every project starts as a blank slate waiting for thoughtful architecture.

Core Principles of This Blog

  • Clarity Over Jargon: Explaining technical concepts in plain, direct language without hiding behind buzzwords.
  • Honest Learning Logs: Sharing the bugs, architecture missteps, and scope adjustments alongside the successes.
  • Human & Accessible Design: Prioritizing comfortable typography, high contrast, and responsive layouts for real readers.

Tools & Tech Stack

This website itself is built entirely with semantic HTML5, modern CSS3 (custom properties, Flexbox, and CSS Grid), and Vanilla JavaScript. It is designed to be completely lightweight, fast-loading, and effortlessly deployable onto GitHub Pages without requiring heavy build steps or server runtimes.
